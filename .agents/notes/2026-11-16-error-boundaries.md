# 错误边界：把「一处渲染失败」限制在最小范围

日期：2026-11-16

## 背景：两次白屏，两类原因

同一周踩了两次「打开工作流整页全白」：

1. **缺字段**：提示词卡只有 `{ prompt }`、没有 `size`。渲染层对 `undefined` 调 `.trim()`
   抛 `TypeError`。
2. **节点骨架不成立**：`manual.json` 里只有一个 `{ "id": "manual" }` ——
   没有 `type`、没有 `position`、没有 `data`。React Flow 自己读 `node.position.x` 就抛了。

两次都**没有错误边界**，于是 React 卸载整棵树：页面全白，界面上没有任何入口自救。
更糟的是崩溃时的卸载 flush 又把坏状态写回恢复快照 —— 一次事故变成「每次打开都崩」。

第 1、2 类本身已经用「加载时补全 + 不合法节点跳过」挡住（见
[2026-11-16-missing-node-fields](2026-11-16-missing-node-fields.md) 与
[2026-11-16-skip-invalid-nodes](2026-11-16-skip-invalid-nodes.md)）。
但那是**枚举已知形状**的做法 —— 下一个没想到的字段、下一处没预料到的读取，照样白屏。
这一层是唯一能兜住**未知**缺陷的东西。

## 两层，职责不同

|                                             | 拦得住                   | 拦不住                |
| ------------------------------------------- | ------------------------ | --------------------- |
| `NodeBoundary`（套在每个节点类型外面）      | 节点组件 render 里抛的错 | React Flow 内部抛的错 |
| `CanvasBoundary`（套在 `<ReactFlow>` 外面） | 画布区任何渲染异常       | 整个插件面板其它部分  |

为什么节点级边界必须包在**组件外面**：组件自己 render 里抛的错，只有它外层的边界接得住。
包在组件内部等于没包。

为什么还要第二层：React Flow 读 `node.position.x` 抛的错发生在**它的内部**，
不在我们任何节点组件的 render 里，节点级边界看不见它。

## 三条设计约束

**1. 没出错时不额外包 DOM。** `ErrorBoundary` 正常路径直接 `return children`。
多套一层 div 会让 React Flow 的节点定位、选择框、拖拽把手算歪 —— 那是看不见的回归。

**2. 替代界面必须给「出路」。** 只写「出错了」等于让用户对着白屏。
节点级给「重试」；画布级给「重试 / 清空画布」，并明说**工作流文件还在磁盘上，没有丢**
—— 白屏时用户第一反应是「我的东西没了」。

**3. 边界吞掉错误后，控制台必须留完整堆栈。**
`componentDidCatch` 里 `console.error` 打 `error` + `componentStack`。
否则以后排查只剩「界面说这张卡出错了」，不知道哪里错 —— 比白屏更难查。

## 崩溃时不再写快照

`crashedRef` 由 `CanvasBoundary` 的 `onCrash` 置位，`use-canvas-workflow` /
`useCanvasRecovery` 的写入路径都先看它。

这是「一次事故变永久」的直接成因：崩溃时组件被卸载，卸载钩子 flush 下去写的
正是那份让页面崩掉的状态。数据侧已经在保存前收敛形状（`lib/recovery.ts`），
这一道是从「**状态可信吗**」的角度再堵一次 —— 两个角度不是重复，是互补。

## 怎么验收

边界只在该触发时才渲染替代界面，正常路径永远看不到。靠「造一份能把画布搞崩的数据」
来验收已经不可靠了：数据侧有形状校验，脏数据会被跳过，根本走不到渲染异常那一步。

所以把边界本身交出去：

- 插件：`globalThis.__dshImagoraBoundary`（与既有的 `__dshImagoraCanvas` 同一性质），
  UI 冒烟直接挂一个「render 里必定 throw」的子树进去，断言 5 条。
- 原版：`ErrorBoundary.test.tsx` 8 条单测，含「点重试真的能恢复正常内容」。

两条踩过的坑写在这里：

- **`page.evaluate` 里的 `document` / `window` 要写 `globalThis.` 前缀**：
  回调在浏览器执行，但 ESLint 按 Node 环境检查，裸写会 `no-undef` 一片。
- **故意抛的错要进冒烟的白名单**：否则最后那条「全程无页面异常」会把它们算成失败，
  等于「验了边界反而证明不了别处没坏」。用完即清空，作用域尽量小。
