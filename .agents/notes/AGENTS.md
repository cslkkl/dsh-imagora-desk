# notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

## 状态行

每篇第 3 行必须是状态行，四值之一：

- `状态：生效`
- `状态：被取代`，必须跟一行指向新记录的指针
- `状态：已否决`，必须跟一句话理由
- `状态：已归档`，必须跟一句话理由

## 分类

触发源决定类型：

- 做选择（在几个方案里挑一个）→ 决策类，命名 `YYYY-MM-DD-<主题>.md`，必须写 `## 替代方案（强制）`。
- 做调查（看事实、对照、得出结论）→ 依据类，命名可省日期，`## 支撑的决策` 有下游才写。

## 写法

- 现在时描述已落地的事实；路径、默认值、机制名变了就地更新。
- 决策被反转时写新记录并交叉引用，不改旧记录结论。
- 不建 `archived/` 子目录，失效记录就地标状态。
- 不建索引文件，读 [README.md](README.md) 即可。

## 边界

- 事故 → `docs/postmortem/`，不进这里。
- 迁移计划、验收清单、spec 式「应该…」→ 不进这里。
