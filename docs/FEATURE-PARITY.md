# 与 Imagora 画布的功能对照

对照对象：Imagora 的**自由画布**（`frontend/src/components/CanvasPage.tsx` 及其对话框）。
插件只搬画布，`表单页 / 批量页 / 配置页` 不在对照范围内。

标记：✅ 一致 · 🟡 有差异 · ❌ 未实现

## 画布与节点

| 功能                   | 状态 | 说明                                                   |
| ---------------------- | ---- | ------------------------------------------------------ |
| 无限画布、缩放、平移   | ✅   | 滚轮缩放、右键或中键拖拽平移                           |
| 图片节点               | ✅   | 缩略图、文件名、引用次数、悬停操作栏                   |
| 提示词节点             | ✅   | 提示词、尺寸、质量、输出路径、运行/取消                |
| 图片组节点             | ✅   | 张数、总大小、去重计数                                 |
| 节点拖拽 / 选中        | ✅   | React Flow 原生                                        |
| 节点拖拽拉伸（右下角） | 🟡   | 图片节点固定 148px；Imagora 可拉伸                     |
| 双击图片放大           | ✅   | 遮罩预览，Esc 关闭                                     |
| 空画布引导             | ✅   | 文案说明怎么开始                                       |
| 小地图                 | ✅   | 可开关                                                 |
| 适应视图（全览）       | ✅   | 工具栏「全览」                                         |
| 吸附对齐辅助线         | ❌   | `lib/snapGuide.ts`、`lib/snapDrag.ts` 已移植，未接界面 |
| 节点锁定               | ❌   | Imagora 工具栏可锁                                     |

## 连线与引用

| 功能                    | 状态 | 说明                           |
| ----------------------- | ---- | ------------------------------ |
| 图片 → 提示词（参考图） | ✅   | 连线即参考关系                 |
| 图片组 → 提示词         | ✅   | 组内图片递归展开               |
| 提示词 → 图片（产出）   | ✅   | 出图后自动连线                 |
| 连线方向约束            | ✅   | `canConnect` 与 Imagora 同规则 |

| 双击连线删除            | ❌   | Imagora 支持双击连线直接删     |

## 结论

画布的**主干**与 Imagora 一致：节点模型、连线语义、`@` 引用、运行与取消语义、结果回流、撤销重做、快捷键、工作流与恢复快照。

差距集中在两类：

1. **图片加工**（裁剪 / 切分 / 放大 / 蒙版）—— Imagora 的增值功能，未移植。
2. **效率辅助**（吸附对齐、锁定、双击删连线、粘贴导入、默认输出路径、成本看板）—— 缺的是操作手感，不影响主流程。

按影响排序的补齐建议：粘贴导入 → 双击删连线 → 默认输出路径 → 吸附对齐 → 成本看板 → 图片加工。
