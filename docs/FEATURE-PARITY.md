# 与 Imagora 画布的功能对照

对照对象：Imagora 的**自由画布**（`frontend/src/components/CanvasPage.tsx` 及其对话框）。
插件只搬画布，`表单页 / 批量页 / 配置页` 不在对照范围内。

标记：✅ 一致 · 🟡 有差异 · ❌ 未实现

## 画布与节点

| 功能                   | 状态 | 说明                                           |
| ---------------------- | ---- | ---------------------------------------------- |
| 无限画布、缩放、平移   | ✅   | 滚轮缩放；左键拖空白平移（与 Imagora 同）      |
| 图片节点               | ✅   | 缩略图、文件名、引用次数、悬停操作栏           |
| 提示词节点             | ✅   | 提示词、尺寸、质量、输出路径、运行/取消        |
| 图片组节点             | ✅   | 张数、总大小、去重计数                         |
| 节点拖拽 / 选中        | ✅   | React Flow 原生                                |
| 节点拖拽拉伸（右下角） | 🟡   | 图片节点固定 148px；Imagora 可拉伸             |
| 双击图片放大           | ✅   | 遮罩预览，Esc 关闭                             |
| 空画布引导             | ✅   | 文案说明怎么开始                               |
| 小地图                 | ✅   | 可开关                                         |
| 适应视图（全览）       | ✅   | 工具栏「全览」                                 |
| 吸附对齐辅助线         | ✅   | 阈值 6px，x/y 各自独立；命中画蓝线；工具栏可关 |
| 节点锁定               | ✅   | 一次停掉拖动/连线/选中/平移，缩放保留          |

## 连线与引用

| 功能                    | 状态 | 说明                            |
| ----------------------- | ---- | ------------------------------- |
| 图片 → 提示词（参考图） | ✅   | 连线即参考关系                  |
| 图片组 → 提示词         | ✅   | 组内图片递归展开                |
| 提示词 → 图片（产出）   | ✅   | 出图后自动连线                  |
| 连线方向约束            | ✅   | `canConnect` 与 Imagora 同规则  |
| `@图片名` 点名引用      | ✅   | 引用不存在时报错并说明缺哪张    |
| 自动连线                | ✅   | 工具栏「自动连线」              |
| 删除连线                | ✅   | 选中后 Delete / Backspace       |
| 双击连线删除            | ✅   | 与 Imagora 一致：双击连线直接删 |

## 运行与结果

| 功能                         | 状态 | 说明                                                    |
| ---------------------------- | ---- | ------------------------------------------------------- |
| 单卡运行                     | ✅   | 卡片「运行」                                            |
| 全部运行 / 运行所选          | ✅   | 工具栏                                                  |
| 取消单卡 / 取消全部          | ✅   | 语义与 Imagora 一致：排队中就地取消，运行中等当前张结束 |
| 结果自动回流成节点           | ✅   | 摆在提示词卡正下方并自动连线                            |
| 运行状态与耗时显示           | ✅   | 状态点 + 秒数                                           |
| 按卡设置输出路径             | ✅   | 提示词卡上的输入框                                      |
| 生成历史（把旧图放回画布）   | ✅   | 列出磁盘上的真实文件，带文件名筛选、可多选导入          |
| 默认输出路径（工具栏统一设） | ✅   | 设置弹窗里改，留空回落到来源根目录                      |
| 成本看板与预算闸门           | ✅   | 工具栏 ¥ 徽章 + 进度条；超限拒提交（409）               |

## 图片加工（Imagora 的高级功能）

| 功能                 | 状态 | 说明                         |
| -------------------- | ---- | ---------------------------- |
| 裁剪                 | ✅   | 可拖可缩的框 + 7 档比例预设  |
| 切分（按网格切多张） | ✅   | 1~6 × 1~6，确认后逐块导出    |
| 放大像素             | ✅   | 长边 1024~4096 + 三档算法    |
| 蒙版重绘             | ❌   | 未移植                       |
| 换一张图             | ✅   | 节点操作栏「换一张图」       |
| 删除图片（含文件）   | ✅   | 节点操作栏，同时删登记与文件 |

## 键盘

| 键位                        | 状态 | 说明                                           |
| --------------------------- | ---- | ---------------------------------------------- |
| Ctrl/Cmd + A 全选           | ✅   | 与 Imagora 同机制（写 selected 标记）          |
| Ctrl/Cmd + Z 撤销           | ✅   | 50 步历史，复用 Imagora 的 createCanvasHistory |
| Ctrl/Cmd + Y / Shift+Z 恢复 | ✅   |                                                |
| Ctrl/Cmd + S 保存           | ✅   | 打开保存弹窗                                   |
| Delete 删节点               | ✅   |                                                |
| Delete / Backspace 删连线   | ✅   | 仅在没选中节点时生效，与 Imagora 互斥逻辑一致  |
| Escape 关预览               | ✅   |                                                |
| 输入框内不拦截              | ✅   | 在提示词里 Ctrl+A 仍是全选文字                 |

## 工作流与持久化

| 功能                  | 状态 | 说明                                   |
| --------------------- | ---- | -------------------------------------- |
| 保存 / 加载命名工作流 | ✅   | 同名覆盖前不额外确认（Imagora 会先问） |
| 加载时同名冲突提示    | 🟡   | 直接覆盖，没有「同名是否覆盖」二次确认 |
| 自动恢复快照          | ✅   | 改动 2.5 秒后落盘，留最近 5 份         |
| 工作流列表            | ✅   | 带修改时间                             |

| -------------------------- | ---- | ------------------------------------ |
| 拖图进画布                 | ✅   |                                      |
| `Ctrl+V` 粘贴图片          | ✅   |                                      |

## 配置

| 功能                           | 状态 | 说明                                      |
| ------------------------------ | ---- | ----------------------------------------- |
| 插件内填接口地址 / 密钥 / 模型 | ✅   | 不依赖本机 Imagora                        |
| 测连通（读模型清单，不花钱）   | ✅   | 设置弹窗里                                |
| 首次使用自动弹设置             | ✅   | 没配置时打开画布即弹                      |
| 沿用本机 Imagora 配置          | ✅   | 两层解析，插件内配置优先                  |
| 切来源（profile）/ 切模型      | ✅   | 工具栏下拉                                |
| 按尺寸计价显示                 | 🟡   | 沿用 Imagora 的价目表；插件内配置时无价目 |
| 密钥不明文回传                 | ✅   | 只回 `apiKeyConfigured`                   |

## 结论

画布的**主干**与 Imagora 一致：节点模型、连线语义、`@` 引用、运行与取消语义、结果回流、撤销重做、快捷键、工作流与恢复快照。

差距集中在两类：

1. **图片加工**（裁剪 / 切分 / 放大 / 蒙版重绘）—— Imagora 的增值功能，未移植。

其余功能性差异已清空：画布、连线、运行、快捷键、工作流、导入、配置、成本都在。
需要补齐的就是这四项图片加工。
